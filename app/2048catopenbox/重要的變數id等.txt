🎨 附錄：重要且不可或缺的「隐藏屬性結構」未來想開發「更強大的套裝功能」、或是要調整數值時，這兩個常數物件的結構是控制整個遊戲好玩與否的命脈：
1. 掉落裝備物件屬性（newDrop 與 equipped 內部結構）每次開箱生成的裝備，在 JavaScript 裡都是一個實心物件，包含以下重要數值：
javascript{
  name: "[永恆] 弒神歌",   // 裝備名稱 (含稀有度標籤)
  slot: "武器",           // 裝備部位 (武器/頭盔/胸甲/鞋子)
  rarity: "永恆",         // 稀有度等級 (影響顏色與數值加權)
  attack: 145000,         // 攻擊力增幅
  defense: 42000,         // 防禦力增幅
  health: 850000,         // 生命值增幅
  sellValue: 540000       // 分解可以賣多少金幣 (通膨加權)
}
2. 神壇升級消耗與稀有度權限（CHEST_LEVEL_CONFIGS）
cost：控制玩家升級寶箱神壇需要消耗多少金幣（第 1 級 100 元，第 30 級高達 5 億元）。
rates：控制該等級下，抽到 10 種不同稀有度的百分比機率（從最初級的 100% 普通，到 30 級時超越、鎏金、永恆高階神裝滿地走）。
